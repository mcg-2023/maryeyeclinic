# 홈페이지 인터랙션 적용 명세

- 참고 사이트: https://www.eye100.co.kr/
- 작성일: 2026-10-08
- 목적: 참고 사이트의 콘텐츠 전환 방식과 유사한 효과를 내 홈페이지에 적용한다.
- 적용 범위: 메인 페이지의 배너, 탭, 카드, 스크롤 등장, 메뉴와 버튼.
- 내 사이트 주소와 기술 스택은 미제공 상태이므로 기존 구조에 맞게 적용한다.

## 1. 확인 범위

참고 페이지에서 확인된 구조:
- 메인에 여러 메시지와 이전·일시정지 컨트롤이 있다.
- 연령별 4개 항목과 대응하는 이미지·설명 콘텐츠가 있다.
- 시설 소개에 이미지와 수치 정보가 있다.
- 서비스 소개에 4개 항목이 있다.
- 연혁이 연도별로 구성되어 있다.
- 장비 소개에 4개 장비명과 상세 콘텐츠가 있다.
- 의료진과 뉴스 영역에 이전·일시정지 컨트롤이 있다.
- 다단계 메뉴와 상담·길찾기 등의 바로가기 항목이 있다.

실제 스크롤·호버·클릭 동작과 원본 CSS/JS는 검증하지 못했다.
아래 전환 방식, 시간, 이동 거리, 반응형 기준은 구현 제안이다.
원본에 해당 효과가 있다고 단정하지 않는다.

## 2. 공통 모션 규칙 — 제안

전체 움직임은 부드럽고 절제된 분위기로 통일한다.

| 구분 | 시작값 | 종료값 | 시간 |
|---|---|---|---|
| 섹션 등장 | opacity 0, y 24px | opacity 1, y 0 | 650ms |
| 제목 등장 | opacity 0, y 20px | opacity 1, y 0 | 600ms |
| 본문 등장 | opacity 0, y 16px | opacity 1, y 0 | 500ms |
| 이미지 전환 | opacity 0 | opacity 1 | 700ms |
| 탭 콘텐츠 전환 | opacity 0, y 12px | opacity 1, y 0 | 300ms |
| 버튼·카드 반응 | 기본 상태 | 강조 상태 | 200~250ms |

- 기본 easing: cubic-bezier(0.22, 1, 0.36, 1).
- 같은 그룹의 요소는 80~120ms 간격으로 순차 등장한다.
- 제목 → 설명 → 버튼 순서로 등장시킨다.
- transform과 opacity를 중심으로 애니메이션한다.
- 모션 때문에 콘텐츠 높이가 바뀌거나 화면이 튀지 않게 한다.
- 초기 콘텐츠는 JS 실패 시에도 읽을 수 있어야 한다.

## 3. 메인 비주얼

### 참고 구조
여러 메시지와 이전·일시정지 컨트롤이 확인된다.
슬라이더 구성으로 추정되지만 실제 자동 전환은 미검증이다.

### 적용 효과 — 제안
- 큰 이미지 위에 제목, 설명, CTA 버튼을 배치한다.
- 배경은 700~900ms 동안 교차 페이드한다.
- 활성 배경에만 scale 1.04 → 1.00의 느린 줌을 적용한다.
- 텍스트는 아래에서 올라오며 순차 등장한다.
- 자동 전환 간격은 우선 6초로 설정한다.
- 이전·다음·재생/일시정지 버튼과 현재 위치 표시를 제공한다.

### 동작 조건
- 수동 이동 시 자동 전환 타이머를 초기화한다.
- 사용자가 일시정지하면 임의로 재생을 재개하지 않는다.
- 마우스 호버, 키보드 포커스, 비활성 브라우저 탭에서 자동 전환을 멈춘다.
- 슬라이드가 1개면 자동 재생과 이동 컨트롤을 숨긴다.
- 모바일에서는 텍스트가 이미지 밖으로 넘치지 않도록 높이를 조정한다.

## 4. 카테고리·장비 탭

### 참고 구조
연령별 4개 항목과 장비별 4개 항목 및 상세 콘텐츠가 확인된다.
탭처럼 전환되는지 여부는 실제 클릭 검증이 필요하다.

### 적용 효과 — 제안
- 내 홈페이지의 서비스 또는 상품 카테고리로 교체한다.
- 활성 탭은 글자색과 밑줄로 표시한다.
- 클릭하면 이미지, 제목, 설명, 링크를 함께 교체한다.
- 이전 콘텐츠를 짧게 페이드 아웃한 뒤 새 콘텐츠를 등장시킨다.
- 이미지 영역의 비율을 고정해 전환 중 레이아웃 이동을 방지한다.
- 빠르게 연속 클릭해도 마지막 선택 내용만 표시한다.

### 모바일·접근성
- 탭이 길면 가로 스크롤을 허용한다.
- 선택된 탭이 화면 안에 보이도록 이동한다.
- tablist, tab, tabpanel 관계와 선택 상태를 제공한다.
- 방향키로 탭 이동, Enter 또는 Space로 선택할 수 있게 한다.

## 5. 스크롤 등장

### 적용 효과 — 제안
- 섹션이 화면에 진입할 때 제목·설명·이미지·카드를 순차 표시한다.
- 요소의 약 15%가 보이거나 화면 하단보다 80px 위에 들어오면 시작한다.
- 기본값은 한 번만 재생한다.
- 큰 이미지는 페이드 중심, 텍스트는 작은 수직 이동 중심으로 구성한다.
- 모바일에서는 이동 거리를 12~16px로 줄인다.

### 구현 조건
- 단순 진입 감지는 IntersectionObserver를 사용한다.
- 모든 스크롤 이벤트마다 요소 위치를 반복 측정하지 않는다.
- 빠르게 스크롤해도 콘텐츠가 숨은 상태로 남지 않아야 한다.
- 스크롤을 강제로 잠그거나 섹션마다 이동시키는 기능은 별도 요구가 있을 때 추가한다.

## 6. 시설·실적 숫자

### 참고 구조
시설 규모와 장비·인원 등에 대한 숫자 정보가 확인된다.
카운트업 효과의 사용 여부는 미검증이다.

### 적용 효과 — 선택 제안
- 내 사이트의 실제 실적이나 규모 데이터로 교체한다.
- 화면에 진입하면 0에서 목표값까지 1,200ms 동안 증가시킨다.
- 단위, 쉼표, 소수 자릿수는 유지한다.
- 한 번만 재생하며 최종값은 원래 콘텐츠에 포함한다.
- 스크린리더에는 반복 중간값 대신 최종값을 제공한다.
- reduced motion에서는 바로 최종값을 표시한다.

## 7. 서비스 카드·연혁

### 서비스 카드 — 제안
- 이미지, 번호, 제목, 짧은 설명, 링크로 구성한다.
- 호버 또는 키보드 포커스 시 이미지 scale을 최대 1.03까지 변경한다.
- 테두리·배경·화살표를 200~250ms 동안 강조한다.
- 카드 높이와 위치는 유지한다.
- 모바일에서는 설명과 링크를 항상 노출한다.

### 연혁 — 선택 제안
- 연도와 내용을 구분한 타임라인으로 구성한다.
- 스크롤 진입 시 항목을 순차 등장시킨다.
- 긴 목록은 모바일에서 세로 흐름으로 배치한다.
- 콘텐츠보다 장식 움직임이 더 눈에 띄지 않도록 한다.

## 8. 팀 소개·뉴스 캐러셀

### 참고 구조
의료진·뉴스 목록과 이전·일시정지 컨트롤이 확인된다.
자동 재생 속도, 이동 방향, 무한 반복 방식은 미검증이다.

### 적용 효과 — 제안
- 내 사이트의 팀 소개, 후기, 사례 또는 뉴스로 교체한다.
- 카드 이동 시간은 500~650ms로 시작한다.
- 데스크톱은 컨테이너 너비에 따라 2~3장, 모바일은 1장을 표시한다.
- 모바일에서 다음 카드의 일부가 보이도록 구성할 수 있다.
- 이전·다음 버튼과 터치 스와이프를 지원한다.
- 자동 재생을 사용할 경우 일시정지 버튼을 제공한다.
- 기본은 유한 목록으로 구현하고 필요할 때 무한 반복을 추가한다.
- 복제 슬라이드를 사용하면 중복 포커스와 중복 읽기를 방지한다.

## 9. 헤더·바로가기·버튼 — 제안

참고 페이지에서 메뉴와 바로가기 항목은 확인된다.
헤더 고정 여부, 드롭다운 방식, 바로가기 위치는 미검증이다.

### 적용안
- 헤더 고정이 필요하면 스크롤 48px 이후 배경과 약한 그림자를 추가한다.
- 메뉴는 포인터와 키보드 모두로 열고 닫을 수 있게 한다.
- 모바일 메뉴는 열기·닫기 버튼과 Escape 닫기를 지원한다.
- 펼친 메뉴가 히어로 컨트롤보다 위에 보이도록 한다.
- 상담·문의 바로가기는 주요 콘텐츠를 가리지 않는 위치에 둔다.
- CTA 화살표는 호버·포커스 시 4px 정도 이동시킨다.
- 터치 환경에서 호버만으로 중요한 정보를 제공하지 않는다.

## 10. 구현 순서

1. 기존 사이트 구조와 컴포넌트, 사용 중인 모션 기능을 확인한다.
2. 메인 배너 전환과 재생 제어를 구현한다.
3. 카테고리·장비 탭을 구현한다.
4. 팀·뉴스 캐러셀을 구현한다.
5. 공통 스크롤 등장과 버튼 반응을 적용한다.
6. 필요한 경우 숫자 카운트업과 연혁 모션을 추가한다.
7. 모바일, 키보드, reduced motion 동작을 검수한다.

단순 효과는 CSS와 기본 브라우저 API로 구현한다.
캐러셀은 기존 프로젝트의 구현이나 라이브러리를 우선 재사용한다.
새 라이브러리를 추가할 경우 기능 중복과 번들 증가를 검토한다.

## 11. 검수 기준

- [ ] 첫 화면의 제목과 CTA가 즉시 확인된다.
- [ ] 배너의 이전·다음·일시정지가 정상 동작한다.
- [ ] 탭 연속 클릭 시 이미지와 설명이 같은 항목을 표시한다.
- [ ] 자동 재생이 사용자의 일시정지 선택을 유지한다.
- [ ] 키보드로 메뉴·탭·슬라이더를 사용할 수 있다.
- [ ] 모바일에서 가로 넘침과 텍스트 잘림이 없다.
- [ ] 이미지 전환과 로딩 중 레이아웃이 튀지 않는다.
- [ ] 빠른 스크롤 후에도 콘텐츠가 전부 보인다.
- [ ] JS 실패 시에도 핵심 콘텐츠와 링크를 이용할 수 있다.
- [ ] prefers-reduced-motion에서 자동 재생과 이동·줌 효과를 끈다.
- [ ] 내 홈페이지의 로고·이미지·문구·데이터로 구성한다.
