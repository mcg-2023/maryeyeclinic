# 비밀 상담 게시판

`node server.cjs`로 실행하는 관리자 서버에서 동작합니다. `/admin/` 로그인 후 **비밀 상담 관리** 또는 `/admin/inquiries/`에서 질문을 확인하고 답변합니다.

공개 목록에는 문의 분야, 가려진 이름, 날짜와 답변 상태만 표시합니다. 제목·본문·답변은 글 비밀번호 또는 관리자 로그인으로 확인합니다. 비밀번호는 salt와 scrypt 해시로 저장합니다. 원문 비밀번호는 저장하지 않습니다.

로컬 데이터는 `.data/inquiries.sqlite`에 저장됩니다. 답변 후 1년이 지난 글은 목록 조회 시 삭제합니다. 저장소는 공개 정적 파일 디렉터리 밖에 유지해야 합니다.

현재 GitHub Pages에는 API 서버가 없으므로 접수가 비활성화됩니다. 공개 서비스에는 이 Node 서버를 영구 디스크가 있는 호스팅에 배포하고 사이트와 API를 같은 origin에서 제공해야 합니다. Vercel 임시 파일 저장소를 영구 게시판으로 사용하지 않도록 `VERCEL` 환경에서는 API가 503을 반환합니다. 별도 영구 저장소 어댑터를 연결하기 전까지 Vercel에서 접수를 활성화하지 않습니다.

검증: `node --test inquiry-service.test.cjs`.
