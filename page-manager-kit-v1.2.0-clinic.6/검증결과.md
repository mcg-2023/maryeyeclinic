UI는 기존 패키지의 Pretendard/브랜드/관리자 셸을 유지하고 Achromatic ledger 방향(seed 183995903)을 적용했습니다. 방문 흐름을 파악하는 화면으로, 브랜드색은 추이 그래프에 사용하고 수치는 실제 집계값을 표시합니다. 사이트 설정은 수집 대상과 설치 코드를, 세션 상세는 유입과 이동 경로를 답합니다. 비교 화면의 샘플 방문 데이터는 검증 서버의 메모리에만 있으며 패키지에 포함하지 않습니다. 패널 높이는 항목 수에 맞춰 두어 빈 영역을 만들지 않았습니다.

실제 Vercel 프로젝트 배포 및 실제 Supabase SQL 실행은 하지 않았습니다. Supabase API 계약은 모의 서버로 확인했으며 운영 적용 후의 확인 순서는 배포 안내에 있습니다. PHP 사이트의 코드와 사용자 원본 ZIP은 변경하지 않았습니다.

최종 UI 검사: 세 너비 모두 0 FAIL. 공유 관리자 셸 일부 보조 글자 대비와 실제 항목 수에 따른 패널 높이 차이에 대한 WARN 2종은 남아 있습니다. 최종 starter 설치·빌드 및 설치된 tgz의 통합 테스트 7개도 통과했습니다. 기본 셸은 기존 디자인을 유지했습니다.
